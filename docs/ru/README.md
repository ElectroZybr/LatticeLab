# LatticeLab

Интерактивная симуляция материи на runtime **Lattice**.

Задаются правила взаимодействия частиц — потенциалы, силы, стенки сосуда — и видно, какое
поведение из них возникает. Без заранее прописанных эффектов: кристаллизация, диффузия,
волны в решётке, границы зёрен, дефекты, плавление и переходы между состояниями рождаются из
простых правил сами.

Зачем: для обучения, для экспериментов и чтобы понимать, как устроена материя.

## Ядро Lattice

Lattice — отдельный репозиторий (по умолчанию `../Lattice` рядом с этим). Его механизмы —
дерево, композиция, Context, слоты, конвейеры, сервисы, экспорты — описаны только там; здесь
на них ссылаются:

| Документ | О чём |
| --- | --- |
| [Lattice](../../../Lattice/docs/ru/README.md) | Что такое Lattice, карта его документации |
| [Архитектура ядра](../../../Lattice/docs/ru/articles/Architecture.md) | Устройство ядра, карта кода |
| [Композиция](../../../Lattice/docs/ru/articles/Composition.md) | `compose`/`configure`, Context, Focus, mount, слоты, конвейеры, сервисы, экспорты, пересборка |
| [Термины ядра](../../../Lattice/docs/ru/articles/Glossary.md) | Узел, ветка, Context, слот, конвейер, сервис, экспорт… |
| [BmRunner](../../../Lattice/docs/ru/articles/BmRunner.md) | Бенчмарки: фазы, исполнители, реализации |
| [BmHistory](../../../Lattice/docs/ru/articles/BmHistory.md) | История бенчмарков, `lbm` |

Ссылки на ядро ведут в локальную копию; когда у Lattice появится публичный репозиторий, они
заменятся здесь.

## Репозиторий

```text
packages/     пакеты Lattice: каждый собирает свою ветку дерева (compose.cpp)
libs/         обычные библиотеки: модели, алгоритмы и их бэкенды, без runtime
docs/         документация
config/       значения runtime по умолчанию
user/         локальные данные пользователя (сохранённая конфигурация), не в git
assets/       ресурсы
app/, legacy/ старое приложение — переносится в пакеты и будет удалено
main.cpp      запуск runtime
lattice.toml  что запускать ([Startup])
```
