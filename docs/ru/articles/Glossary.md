# Термины

Слова LatticeLab. Термины ядра (узел, ветка, Context, слот, конвейер, сервис, экспорт…) —
в [терминах Lattice](../../../../Lattice/docs/ru/articles/Glossary.md).

| Термин | Что это |
| --- | --- |
| **Библиотека** | `libs/<name>`: код без ветки и без runtime. |
| **Модель / бэкенд** | Данные алгоритма и их смысл / исполнение модели на устройстве (`cpu`, `wgpu`). |
| **Очередь команд** | `Tasks::Queue` потока-владельца: чужие потоки меняют и читают состояние только её командами. |
| **SoA** | Таблица структур массивов (`StdData::SoA`): колонка на поле. |
| **GPU-копия** | Зеркало данных симуляции на GPU в ветке рендера (`GpuSoA`, `GpuBoundaries`). |
| **Вьюпорт** | Сцена окна: область, камера, контроллер, объекты сцены, свет. |
| **Объект сцены** | То, что вьюпорт рисует: сферы частиц, сетка (`MeshObject`). |
| **Пространство (Space)** | Коробка симуляции и её периодичность по осям. |
| **SDF-форма** | Форма области как функция расстояния: `d > 0` — внутри, `d < 0` — в стенке. |
| **Программа формы** | Форма, скомпилированная в постфиксный байткод; одна для CPU и GPU. |
| **Закон стенки** | Отклик поверхности на частицу: `Hard` (выталкивание и отражение), `Soft` (сила слоя). |
| **Surface nets** | Построение сетки треугольников по значениям SDF в узлах сетки. |
| **Брик** | Блок 8³ ячеек; обрабатываются только брики у поверхности. |
| **Режим отображения** | Как рисуется сетка: затенённый, с кромками, скрытые линии, каркас. |
| **Бенч / работа / реализация** | Замер (BmRunner); работа — что измеряется; реализации — варианты её исполнения (`cpu`, `gpu`). |
| **lbm** | Инструмент истории бенчмарков. |
