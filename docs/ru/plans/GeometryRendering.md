# Отрисовка геометрии

Стенки симуляции видны в Graphics: сетка по SDF (`SdfMesh`, surface nets на GPU) и общие
сетки (`MeshObject`: свет, режимы CAD, прозрачность). Трассировка лучами испробована и
удалена — сетка в 20 раз дешевле.

## Этапы

- [x] Отрисовка геометрии трассировкой (`GeometrySurface`) и codegen расстояния (`Boundaries::Wgpu::generateDistance`: операции в коде, параметры — данные) — codegen в 2 раза быстрее интерпретатора, но трассировка всё равно 13 мс на кадр 1080p вблизи; заменена сеткой и удалена
- [x] Graphics: сетки и свет — `GpuMesh`, `MeshObject` (Блинн–Фонг, каркас, прозрачность, отсечение задних граней), `Light` — узел сцены; бенч `Mesh`: 1 млн треугольников в 1080p — 0.7 мс
- [x] `SdfMesh : GpuMesh` — сетка по SDF на GPU: surface nets в бриках 8³, только брики у поверхности; CPU-эталон `surfaceNets`, эквивалентность; перестройка по `onMaintain` при смене программы или разрешения. Бенч `SdfMesh`: построение 128³ — 0.9 мс, 512³ — 13 мс; кадр вблизи стенки 1080p — 0.65 мс (трассировка — 13.4 мс)
- [x] Режимы отображения как в CAD (`MeshObject::display`): затенённый, с кромками, скрытые линии удалены, скрытые линии видимы (пунктир), каркас; линии формы — изломы (`creaseAngle`), силуэт и граница по буферу рёбер (`meshEdges` на CPU, проход `outline` в `SdfMesh`); сетка треугольников — отдельный `triangles`
- [ ] Линии: отбор рёбер-кандидатов (изломы постоянны, силуэт — каждый кадр) вместо всех рёбер в вершинном шейдере — «скрытые линии видимы» на 1 млн треугольников стоит 3.6 мс против 0.7 мс сплошного
- [ ] Уровни детализации по бликам (экранная ошибка), швы между уровнями
- [ ] Острые рёбра: dual contouring с QEF по аналитическим нормалям
- [ ] Перестройка без ожидания хоста: непрямая отрисовка (`drawIndirect`), число треугольников не читается на CPU
- [x] Программа из симуляции: `ParticleSystemAPI::boundaries()`, копия `GpuBoundaries` командой очереди при смене версии; хардкод в Graphics удалён
