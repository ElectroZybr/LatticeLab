# Границы симуляции

Проект — [Boundaries.md](../articles/Boundaries.md): `Space`, SDF-геометрия, законы стенок, модель и
бэкенды CPU/WGPU. Встраивание в шаг и форма строкой — [шаг симуляции](SimulationStep.md),
отрисовка — [отрисовка геометрии](GeometryRendering.md).

## Этапы

- [x] `libs/boundaries`: `Space` — коробка, периодичность по осям, минимальный образ, заворот (в т. ч. на несколько длин, пакетно по колонкам SoA) + тесты
- [x] `Geometry`: SDF-программа (байткод + стековая машина на CPU, блоками по 64 точки), примитивы (коробка, сфера, капсула, цилиндр, полупространство, бесконечные вдоль оси), операции (объединение, пересечение, вычитание, сглаженное объединение, скругление, оболочка, перенос/поворот/масштаб); результат `{d, материал, движение}`; тесты точности расстояния и нормали
- [x] Построитель `Shape` (значение: булевы операции — конкатенация постфиксного кода, преобразования вливаются в матрицы примитивов, равномерный масштаб масштабирует и параметры операций)
- [x] Проверка согласованности геометрии на периодическом шве (`checkPeriodicSeams`)
- [ ] Проверка толщины стенки против `|v|·dt` — при встраивании в шаг (нужны скорости и `dt`)
- [x] `Walls`: законы `Open`/`Hard` (выталкивание итерациями, отражение с коэффициентом восстановления)/`Soft` (степенной слой с отсечкой), стадии `Constrain`/`Force`, таблица материалов (запись 32 байта, материал 0 по умолчанию); порции по 256 частиц, нормали и выталкивание пакетом только у стенок; тесты: отражение, сила = −dU/dy численно, выбор закона по материалу; бенчи
- [ ] Относительная скорость движущейся поверхности в `Hard` — вместе с анимацией
- [ ] Анимация: аниматор «время → параметры», предыдущий буфер параметров, нормальная скорость поверхности разностью, касательная — из жёсткого движения; тест поршня (работа над газом) и вращающейся мешалки
- [ ] Разметка ячеек сетки соседей (внутри / у поверхности / снаружи) с запасом на движение; `SpatialGrid` по `Space`
- [x] Встраивание в ClassicMD: шаг — конвейер узлов (`Lattice::Pipeline`: predict → constraints → forces → correct), `Space`/`Geometry`/`Walls`/`Boundary` — узлы ветки; 1000 атомов в сосуде, упругие стенки сохраняют энергию
- [ ] Параметры стенок (восстановление, `Soft`) через `executeOn(commands)`; сцена из файла вместо хардкода сосуда
- [x] Раскладка модели и бэкендов: `Boundaries` (модель: Space, Shape/Program, материалы, законы, `ParticleLayout`) и `Boundaries.cpu` (`boundariescpu/`, namespace `Boundaries::Cpu`: Geometry, Walls, `wrapPositions`, проверки); `Walls` на `StdData::SoA` + `ParticleLayout` (имена колонок, строки `[0, rows)`); `SoA::span<T>(name)`
- [x] `Boundaries.wgpu` (`boundarieswgpu/`, `Boundaries::Wgpu`): WGSL-стековая машина из C++ (коды операций и законов — из моделей), `GpuGeometry`, `GpuWalls` (стадии записывают проходы в чужой `CommandList`, без submit), `GpuDistances`; ошибки шейдера — исключение при создании; тест эквивалентности CPU и WGPU (расстояния каждого примитива и операции, стенки, лимит глубины); бенчи CPU против WGPU
- [x] Аналитические нормали в стековой машине (CPU и WGSL): градиент идёт со значением через операции, одно вычисление вместо четырёх; проверка материалов — общая `checkMaterials` в модели
- [ ] Codegen для стенок: генератор есть (`Boundaries::Wgpu::generateDistance`, в 2 раза быстрее интерпретатора), подключить к `GpuWalls` и сравнить реализации в `Boundaries.bench`
