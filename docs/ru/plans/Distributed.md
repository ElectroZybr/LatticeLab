# Распределённое исполнение

Алгоритмы уже сейчас пишутся по правилам «ядро на раздел» (см. `AGENTS.md`), распределение —
отдельная библиотека.

## Этапы

- [ ] `libs/parallel`: разбиение `Space` на подобласти с полосой гало, миграция частиц между разделами, обмен гало через очереди владельцев
- [ ] Балансировка: сначала явные доли разделов в конфигурации, затем подстройка по измеренному времени шага каждого устройства
- [ ] Композиция: разделы и бэкенды размещаются пакетом симуляции; дерево показывает владельцев разделов
- [ ] Оценить StarPU / Kokkos / SYCL как реализацию `libs/parallel` или бэкенд, когда появится конкретная машина (несколько GPU / кластер)
