# Инструменты runtime

Работа с деревом и экспортами во время выполнения: инспектор, пересборка веток, выборы
слотов в конфигурации.

## Этапы

- [ ] Инспектор параметров (GUI поверх `ExportsView` / `TreeView`)
- [ ] Пересборка веток из CLI: смена выбора слота (контроллер, интегратор) с retire → maintain → choice
- [ ] Сохранение выборов слотов в конфигурации (Serializer)
