# Проверка параметров при записи

Параметр объявляет правила (`range`, `choices`, `maxLength`) или свой сеттер; запись
возвращает отказ с подробностями (код, сообщение, участок ввода, допустимое), и CLI, GUI и
Serializer показывают его одинаково. Механизм — в ядре; здесь — его использование.

## Ядро

- [ ] Правила, свои сеттеры и отказ при записи — [план ядра](../../../../Lattice/docs/ru/plans/ParamValidation.md)
- [ ] Имя шаблонного типа в дереве — [план ядра](../../../../Lattice/docs/ru/plans/Kernel.md)

## CLI

- [ ] Отказ с подсветкой участка ввода и списком допустимого
- [ ] Правила параметров в `exports` и `help`: `dt = 0.01 [1e-06 … 0.1]`, `display ∈ {…}`

## Serializer

- [ ] Значение из конфигурации, не прошедшее правила, — предупреждение, остаётся значение по умолчанию
- [ ] Неизвестный ключ — предупреждение, а не остановка запуска

## Правила существующих параметров

- [ ] `MeshObject::display` — `choices`; `opacity`, ширины линий, `creaseAngle` — `range`; `SdfMesh::resolution` — `range`
