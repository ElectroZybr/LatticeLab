# Бенчмарки

Инструмент замеров и истории: BmRunner (фазы, исполнители, реализации) и `lbm`
(история результатов). Проекты — `../Lattice/docs/ru/articles/BmRunner.md` и
`../Lattice/docs/ru/articles/BmHistory.md`. Бенчи — цели `<Name>.bench` рядом с кодом.

## Фазы и исполнители

Работа через канал к исполнителю раскладывается на фазы (`Prepare`, `Transfer`, `Issue`,
`Execute`, `Complete`, `Unaccounted`); длительности исполнителя приходят отдельно от часов
хоста; режимы `Resident` / `Offload`, подгонка `a + b·N` и порог `N*` для пары исполнителей.
На CPU канал — иерархия памяти: `Resident` / `Offload` — горячий / холодный кеш.

- [x] BmRunner: `Phase`, `Trace`, capability `Phases`, подгонка `fixed + per·N` по фазам, пары исполнителей и `N*`, холодный кеш, вывод, тесты на синтетическом исполнителе
- [x] Время GPU в `Trace` через `deferIntervals` (договорённость по форме интервала, без адаптера к `Wgpu::Timer`)
- [x] `Wgpu.bench`, `Boundaries.bench`, `Graphics.bench`: фазы, пары CPU/GPU, `Resident` / `Offload`
- [x] Методика замеров GPU: `flush()` после загрузки (иначе копия попадает в измеряемую итерацию), сброс `Resident` копией на GPU, фикстура на точку N (`Reuse`)
- [ ] Ось `Batch`, калибровка уровней памяти и оценка переноса по счётчикам, объявленный объём работы

## Реализации алгоритма

Одна работа с несколькими реализациями (`cpu`, `gpu`, `codegen`) и осями исполнения
(`workers`, `batch`), вывод «реализации рядом»; имена реализаций = имена вариантов слотов,
позже профиль машины выбирает вариант (ручной выбор главнее).

- [x] BmRunner и `lbm`: реализации, оси параметров, TSV `implementation`/`params`, вид «реализации рядом»
- [x] Открытая регистрация: `BENCH_WORK` / `BENCH_IMPLEMENTATION` из любых модулей, сверка с эталоном, оси-типы (`Tasks::Workers`), TSV `variant`/`unit`
- [x] Бенчи стенок и `Compute` на реализациях
- [ ] Профиль машины и автовыбор варианта слота

## История

Самостоятельный инструмент `lbm` рядом с Lattice; результаты — git-репозиторий
`lbm-results/` в папке запуска (папка на машину, TSV-файл на набор, коммит на
запуск с трейлерами окружения), baseline — теги; деградации — статистикой по семплам и
поиском точки сдвига по истории.

- [x] BmRunner: `RunResult` в TSV, `Benchmarks::main` (`--list`, `--filter`, `--tsv`), семплы в результатах
- [x] BmHistory: репозиторий результатов, окружение, baseline, статистика, история
- [x] `lbm`: `list`, `run`, `log`, `show`, `compare`, `history`, `regressions`, `tag`; `lbm.toml`
- [x] LatticeLab: наборы через `Benchmarks::main`, `.gitignore`; `lbm.toml` не нужен (наборы — цели `*.bench`)
- [x] Установка `lbm`: `xmake install-lbm` в `../Lattice`; поиск наборов через xmake
- [ ] `lbm`: вывод `--tsv`/`--json`, Windows, тесты `lbm.toml`
